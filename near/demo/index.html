NEAR Security Oracle

Before an agent or a protocol pays or calls a NEAR account, it asks the oracle. The oracle reads the account (age, code changes, prior interactions, a shared blocklist with evidence) and scores the contract's Rust code with a model trained on real NEAR vulnerabilities (audits, fix commits, hacks), then answers allow, warn or block with reasons.
